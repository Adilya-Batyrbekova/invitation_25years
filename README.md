# Birthday invitation project

Preparation completed on 2026-10-27 after two interview rounds. The planned product is a Russian invitation for a 25th birthday on 2026-11-28, 14:00–18:00, at the church building at Abaya 89 (large hall), Astana. Launch deadline: 2026-11-18.

The current deliverable is a local responsive design draft in `invitation/`, authorized on 2026-10-28. It implements the four guest pages, envelope entry, painted illustrations, scroll motion, optional music, forms and gift filtering. Database persistence, administrator functionality and external integrations are not implemented. GitHub Pages publication of this static draft was authorized on 2026-10-29. The repository is public and the static draft is live at https://adilya-batyrbekova.github.io/invitation_25years/. `sites/birthday-structure/dist/` is an earlier demonstration, not the current application.
